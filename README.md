## How to use this

1. **Fork the repo** — then tick checkboxes in your own copy as you go.
2. **Work in order.** The lists are sequenced, not sorted by difficulty — each is tagged `Easy` / `Medium` / `Hard` so you can trade breadth for depth when time is short.
3. **Time-box.** The estimate next to each question is roughly what a solid spoken answer takes. If you're well over, that's the gap to study.
4. **Click through to answer.** Reading a question and *thinking* you could answer it is the classic prep trap.
